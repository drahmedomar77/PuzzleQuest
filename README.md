# لمعة ✨ — ألغاز الذكاء وتحدي النطق

تطبيق أندرويد (Flutter) عربي بالكامل:

- **ألغاز الذكاء**: 45 سؤالاً في 3 مستويات (سهل ← متوسط ← صعب)، كل مستوى 3 مراحل × 5 أسئلة، مع مؤقت وتلميحات.
- **تحدي النطق**: 24 عبارة (أمثال وجمل صعبة النطق) بالمستويات الثلاثة، التطبيق يستمع لك ويعطيك نسبة دقة النطق.
- **تحدي اليوم**، **سلسلة أيام متتالية**، **نجوم** (حتى 3 لكل مرحلة)، **لمعات** (عملة داخلية)، ورتبة للاعب (مبتدئ ← عبقري).
- **الأرباح**: بانر أسفل الشاشات + إعلان بيني كل مرحلتين + إعلان مكافأة (تلميح مجاني / مضاعفة الجائزة).

> نتائج التطبيق للتسلية والتدريب، وليست اختبار IQ سريرياً.

---

## 1) رفع المشروع على GitHub

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `lamaa-app`).
2. ارفع **كل محتويات** هذا المجلد (بما فيها المجلد المخفي `.github`).
   - من الموقع: `Add file > Upload files` ثم اسحب الملفات. تأكد أن `.github/workflows/build-apk.yml` ظهر في المستودع.
   - أو من الطرفية:
     ```bash
     git init
     git add .
     git commit -m "first commit"
     git branch -M main
     git remote add origin https://github.com/USERNAME/lamaa-app.git
     git push -u origin main
     ```

## 2) الحصول على ملف APK

بعد الرفع يبدأ البناء تلقائياً (أو من تبويب **Actions > Build APK > Run workflow**).
عند اكتماله (حوالي 5–10 دقائق) افتح التشغيل الناجح، ونزّل الملف من قسم **Artifacts** باسم `lamaa-apk`.
فك الضغط وثبّت `app-release.apk` على هاتفك.

> بالطبع المشروع لا يحتوي مجلد `android/` عمداً؛ يُولَّد أثناء البناء ثم يُعدَّل بالسكربت `tools/patch_android.py` (صلاحيات الميكروفون، معرّف AdMob، الاسم...).

### بناء محلي (اختياري)
```bash
flutter create --platforms=android --org com.lamaa .
python3 tools/patch_android.py
flutter pub get
flutter run            # أو: flutter build apk --release
```

## 3) تفعيل الأرباح من الإعلانات (AdMob)

الإعلانات الآن تعمل بمعرّفات **الاختبار** الرسمية من Google (آمنة، ولا تُحتسب أرباحاً).

1. أنشئ حساباً على [AdMob](https://admob.google.com) وأضف تطبيق أندرويد.
2. أنشئ 3 وحدات إعلانية: **Banner**، **Interstitial**، **Rewarded**.
3. في GitHub: `Settings > Secrets and variables > Actions > Variables` أضف:

| اسم المتغير | القيمة |
|---|---|
| `ADMOB_APP_ID` | `ca-app-pub-XXXX~YYYY` (معرّف التطبيق) |
| `ADMOB_BANNER` | معرّف وحدة البانر |
| `ADMOB_INTERSTITIAL` | معرّف الإعلان البيني |
| `ADMOB_REWARDED` | معرّف إعلان المكافأة |
| `APP_ORG` | مثلاً `com.yourname` (يصبح معرّف الحزمة `com.yourname.lamaa_app`) |

4. شغّل **Build APK** من جديد.

⚠️ **مهم جداً**: لا تضغط على إعلاناتك الحقيقية بنفسك أبداً ولا تطلب من أحد ذلك، فهذا يؤدي لإغلاق حساب AdMob. استخدم معرّفات الاختبار أثناء التطوير.

## 4) النشر على Google Play

- يجب توقيع التطبيق بمفتاح خاص (الـ APK الحالي موقّع بمفتاح debug ويصلح للتجربة والتثبيت المباشر فقط). Google Play تطلب **AAB** وتوقيعاً: راجع https://docs.flutter.dev/deployment/android
- جهّز **سياسة خصوصية** (مطلوبة لأن التطبيق يستخدم الإعلانات والميكروفون) وعبّئ قسم **Data safety** بدقة.
- لا تحدد التطبيق للأطفال دون 13 سنة إلا إذا التزمت بسياسة Families؛ الأفضل جعله لعمر 13+.
- التعرف على الصوت يعتمد على خدمة Google في الهاتف (يعمل بشكل أفضل مع الإنترنت).

## 5) تعديل وتوسعة المحتوى

كل الأسئلة وعبارات النطق في `lib/questions.dart`. لإضافة مستوى أو مراحل: غيّر عدد الأسئلة في القوائم (يجب أن يكون المجموع = عدد المراحل × 5 للألغاز، و × 4 للنطق).

## أفكار لجعله أكثر جذباً

1. **أسئلة جديدة أسبوعياً** عبر ملف JSON على الإنترنت (يمنع الملل ويعيد اللاعبين).
2. **مصابيح/أرواح** محدودة تتجدد بالوقت أو بمشاهدة إعلان.
3. **لوحة المتصدرين** (Firebase) ومشاركة النتيجة كصورة عبر واتساب.
4. **ألغاز صور وأنماط** (مصفوفات وأشكال) واختبار ذاكرة.
5. **صوت وحركات** (تأثير احتفال عند الإجابة الصحيحة).
6. **اشتراك بدون إعلانات** كمصدر دخل إضافي.
7. إضافة خط عربي جميل مثل Cairo عبر مجلد `assets/fonts`.

## الاختبار الخاطف وبطاقة النتيجة (جديد)

- **الاختبار الخاطف** (`lib/quick_test_screen.dart`): 10 أسئلة من بنك الألغاز نفسه (3 سهلة، 4 متوسطة، 3 صعبة) مع تنويع المهارات، ولكل سؤال زمن مستواه (25/20/15 ثانية). الأسئلة والخيارات تُخلط في كل مرة.
- **مؤشر لمعة (0 ← 100)** (`lib/quick_logic.dart`): كل إجابة صحيحة تعطي وزن صعوبتها (1/2/3) مع خصم حتى 25% لمن يستهلك كل الوقت. هو مقياس للتسلية والتدريب وليس IQ، ولا تُعرض أي نسب مقارنة بالآخرين.
- **رادار من 5 محاور** محسوبة من إجابات اللاعب الفعلية: الأنماط، الحساب، اللغة والمعرفة، المنطق، السرعة. المهارة تُستنتج من نص السؤال في `skillOf` (عدّلها إن أضفت أنواعاً جديدة).
- **بطاقة النتيجة** (`lib/result_card.dart`): صورة 1080×1350 يرسمها `ResultCardPainter`، وهو نفسه ما يُعرض في التطبيق وما يُشارك عبر `share_plus`.
- المكافأة: 5 إلى 15 لمعة حسب المؤشر. يُخفى البانر أثناء الأسئلة لتجنب النقرات العرضية، ويُحتسب الاختبار ضمن عدّاد الإعلان البيني.
- ضع رابط التطبيق في `kShareLink` (`quick_logic.dart`) بعد النشر ليُضاف إلى نص المشاركة.
- أضفنا الحزمتين `share_plus` و`path_provider` في `pubspec.yaml`.
