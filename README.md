# تحدّي الألغاز / Puzzle Quest

لعبة ألغاز أندرويد (Kotlin + Jetpack Compose) بثلاثة أقسام متدرجة: **سهل ← متوسط ← صعب**.
30 مستوى في كل قسم (90 مستوى)، وواجهة عربية وإنجليزية بزر تبديل.

## أنواع الألغاز (تتناوب في كل قسم)
- **تسلسل الأرقام:** سهل (جمع/طرح/ضرب بـ2) ← متوسط (مربعات، فيبوناتشي، فرق متزايد، تناوب) ← صعب (ضرب+جمع، متتاليتان متداخلتان، أعداد أولية، مكعبات).
- **معادلات الرموز:** رمزان ← ثلاثة رموز متسلسلة ← ثلاثة رموز متقاطعة والمطلوب حاصل ضرب.
- **الشكل المختلف:** فئات بعيدة (سهل) ← فئات متقاربة من العائلة نفسها (متوسط وصعب) مع زيادة عدد الأشكال.

الألغاز تُولَّد برمجياً بقاعدة ثابتة لكل مستوى، فلا تتغير بين مرة وأخرى، ويمكن زيادة المستويات بتغيير `LEVELS_PER_TIER` في `Model.kt`.

## نظام اللعب
- القسم التالي يُفتح بحلّ 20 مستوى من القسم الذي قبله (`UNLOCK_AT`).
- 3 تلميحات في البداية؛ التلميح يستبعد جواباً خاطئاً. وتلميح مجاني عند أول حلّ لكل مستوى خامس.
- عند نفاد التلميحات يظهر **إعلان تجريبي** (عدّاد 3 ثوانٍ) يمنح تلميحاً.
- بعد كل حلّ يظهر شرح القاعدة بالعربية أو الإنجليزية.
- التقدم محفوظ على الجهاز.

## بناء الـ APK
عبر GitHub كما فعلنا سابقاً: ارفع **محتويات** المجلد إلى مستودع جديد، وتأكد من وجود `.github/workflows/build.yml`،
ثم من تبويب Actions نزّل `puzzle-apk`. الملف يشغّل أيضاً اختبارات الألغاز؛ إن فشلت يظهر ذلك في السجل دون إيقاف البناء.
أو افتح المجلد في Android Studio واضغط Run.

## ربط الإعلانات خطوة بخطوة
1. **(الحالية)** إعلان تجريبي محاكى في `Ads.kt` لتجربة التدفق.
2. إنشاء حساب AdMob وتطبيق فيه، ثم استبدال `RewardedAdGate` بإعلان مكافأة حقيقي (بمعرّفات الاختبار الرسمية أولاً).
3. إعلان بيني خفيف كل عدة مستويات + شاشة موافقة المستخدم (UMP) المطلوبة في بعض المناطق.
4. سياسة خصوصية، ثم نسخة موقّعة AAB، ثم النشر في Google Play.
